## Released Games

Since you're here, you should check out [Wordwalker](https://github.com/alexman37/wordwalker), the project I'm most proud of so far. It's a fully playable, complete puzzle game about spelling tricky words using context clues. It was designed for both PC and mobile platforms. I developed all of it by myself over the course of 5 months (with a full time job in tow). I released it on itch ([link](https://greeneagles.itch.io/wordwalker)) and the App Store ([link](https://apps.apple.com/us/app/wordwalker/id6749601380)). Check out the readme in that repository for more information (and how to play it!)

- [Guess Whomstdve](https://github.com/alexman37/GuessWhomstdve): It's sort of like "Guess Who" but with up to many billions of potential suspects (10,000,000,000 to be exact) instead of the usual 24. The database of characters isn't actually a database (it'd obviously be way too big), but instead, "randomly" generated on the fly with predictable outcomes. I used some number tricks and knowledge of pseudorandom generation to make this work. Writeup coming soon!

The project has working multiplayer, and features a number of interesting handcrafted shaders (it's how all the character sprites are drawn and shown at once.)

## Game Jams and Small Projects

- [The Green Door](https://github.com/alexman37/green-door): A top-down RPG about a therapist struggling to move on. Made in 1 month. I built from scratch a grid-based character movement system (a prominent feature in these types of games), and 3 major puzzles structured around this movement: a "Rush Hour" like unjamming puzzle, a walking on ice puzzle, and a big maze. I also did most of the 2D art for this game, although it's not my specialty.

- [Murder Mystery at the Masquerade](https://github.com/alexman37/masquerade): A murder mystery centered around a logic puzzle, where you talk to various attendees of a masquerade party and figure out their roles in a yet-to-happen murder case. I designed the logic puzzle and how the player would go about solving it, but the main thing I programmed was the Portable Dialogue System - a simple, highly configurable way for parsing character dialogue from text files. I've been able to use the system in other projects, like The Green Door.
